# 🏋️‍♂️ سامانه مدیریت هوشمند و آنلاین باشگاه ورزشی اکسیژن (Gym-App)

یک وب‌اپلیکیشن فول‌استک، مدرن و شیشه‌ای (Liquid Glassmorphism) برای مدیریت کامل اشتراک‌ها، برنامه‌های ورزشی، حضور و غیاب آنلاین، رزرو کلاس‌های گروهی و تحلیل پیشرفت ورزشکاران با واحد پولی **تومان**.

---

## 🚀 تکنولوژی‌ها و فناوری‌های اصلی (Tech Stack)

- **فریم‌ورک پایه**: [Next.js 15](https://nextjs.org/) (App Router & React Server Components)
- **زبان توسعه**: TypeScript
- **پایگاه‌داده و ORM**: [Prisma ORM](https://www.prisma.io/) (پشتیبانی کاملاً آماده از SQLite و PostgreSQL)
- **سیستم احراز هویت**: NextAuth.js v5 (مبتنی بر استراتژی JWT و Credentials با رمزنگاری bcryptjs)
- **طراحی و رابط کاربری**: Tailwind CSS + Vanilla CSS (سیستم اختصاصی Liquid Glass، افکت‌های Backdrop Filter و انیمیشن‌های روان)
- **پردازش تصویر و بارکد**: html5-qrcode (اسکنر زنده وب‌کم کلاینت) و qrcode
- **واحد پولی و زبان**: ۱۰۰٪ فارسی (RTL)، تقویم خورشیدی و قیمت‌گذاری به تومان.

## ⚡ راهنمای نصب و راه‌اندازی پروژه (Quick Start)

### ۱. نصب پیش‌نیازها
ابتدا وابستگی‌های پروژه را نصب کنید:
```bash
npm install
```

### ۲. تنظیم متغیرهای محیطی
یک فایل `.env` در ریشه پروژه با محتوای زیر بسازید:
```env
DATABASE_URL="file:./dev.db"
NEXTAUTH_SECRET="gym-app-ultra-secure-secret-key-2026"
NEXTAUTH_URL="http://localhost:3000"
```

### ۳. سینک پایگاه‌داده و مقداردهی اولیه (Seed)
دستورات زیر ساختار جداول را اعمال کرده و حساب‌های تست اولیه را می‌سازند:
```bash
npx prisma db push
npx prisma db seed
```

### ۴. اجرای سرور توسعه
```bash
npm run dev
```
اپلیکیشن در آدرس [http://localhost:3000](http://localhost:3000) (یا پورت ۳۰۰۱) در دسترس خواهد بود.

## ✨ ویژگی‌ها و بخش‌های اصلی سیستم

### 👔 ۱. پنل مدیریت باشگاه (Manager Portal)
- **پیشخوان زنده (Dashboard)**: نمایش شاخص‌های کلیدی عملکرد شامل تعداد اعضای فعال، درآمد کل ماه به تومان، ثبت‌های امروز و اشتراک‌های در شرف انقضا.
- **مدیریت اعضا (`/manager/members`)**:
  - ثبت‌نام اعضای جدید با کد عضویت یکتا (`MEM-XXX`).
  - تعریف و ویرایش برنامه‌های ورزشی پویا (نام حرکت، ست‌ها، تکرارها و یادداشت مربی).
  - مشاهده تاریخچه فاکتورها، پرونده پزشکی و شماره اضطراری عضو.
- **مدیریت حضور و غیاب (`/manager/attendance`)**:
  - **اسکنر زنده QR با وب‌کم**: فعال‌سازی آنلاین دوربین لپ‌تاپ یا سیستم پذیرش جهت خوانش فوری بارکد عضویت و ثبت چک‌این.
  - ثبت دستی ورود با کد عضویت و نمایش لیست لحظه‌ای تردد امروز.
- **تایید فیش‌ها و پرداخت‌ها (`/manager/payments`)**:
  - بررسی و تایید فیش‌های کارت‌به‌کارت معلق کاربران (فعال‌سازی اتوماتیک دوره اشتراک پس از تایید).
  - ثبت دستی پرداخت‌های نقدی یا کارتخوان در باشگاه.
- **کلاس‌های گروهی (`/manager/classes`)**:
  - تعریف کلاس‌های جدید (یوگا، کراس‌فیت، پیلاتس) با تنظیم ظرفیت، مربی، مکان و زمان برگزاری.
- **مدیریت تعلیق‌ها (`/manager/freeze-requests`)**:
  - بررسی و تایید/رد درخواست‌های مرخصی اعضا همراه با افزوده شدن خودکار روزهای تعلیق به انتهای دوره اشتراک.

### 👤 ۲. پنل اعضای باشگاه (Member Portal)
- **پیشخوان هوشمند (`/member/dashboard`)**:
  - کارت هوشمند عضویت شیشه‌ای با نمایش وضعیت اشتراک.
  - ویجت‌های روزشمار باقیمانده اشتراک و تعداد جلسات حضور یافته.
  - چک‌لیست تمرینی روزانه تعاملی (امکان تیک زدن حرکات).
  - **ثبت وزنه‌ها و تکرارها در هر ست**: ثبت دقیق کیلوگرم وزنه زده شده برای پایش قدرت بدنی.
- **عضویت و پرداخت‌ها (`/member/membership` & `/member/payments`)**:
  - دریافت کد QR اختصاصی ورود.
  - تمدید اشتراک آنلاین با درگاه شبیه‌ساز بانک (با تایمر معکوس و درخواست رمز پویا).
  - ثبت فیش کارت‌به‌کارت با کد رهگیری بانک.
- **پایش پیشرفت بدنی و ورزشی (`/member/progress`)**:
  - **نمودار پیشرفت قدرت عضلانی**: رسم داینامیک روند افزایش وزنه‌های جابجاشده در طول جلسات برای هر حرکت.
  - **نمودار فعالیت تمرینی**: نمایش میله‌ای تعداد حرکات انجام‌شده در ۷ روز اخیر.
  - **تحلیل تغییرات بدن**: مقایسه خودکار اولین ثبت بدو ورود با وضعیت فعلی (وزن، چربی، سایز عضلات).
- **رزرو کلاس‌های گروهی (`/member/bookings`)**:
  - مشاهده لیست کلاس‌های فعال، آمار ظرفیت باقیمانده، و امکان رزرو یا لغو رزرو.
- **ثبت مرخصی/تعلیق (`/member/membership`)**:
  - ارسال فرم درخواست تعلیق اشتراک با درج علت و بازه زمانی.

## 🛠 دستورات کاربردی پروژه (CLI Scripts)

- `npm run dev`: اجرای سرور توسعه به همراه لود داینامیک سرور اکشن‌ها
- `npm run build`: بررسی صحت تایپ‌ها و ساخت بیلد بهینه تولید (Production Build)
- `npx prisma db push`: سینک ساختار مدل‌های Prisma با دیتابیس
- `npx prisma db seed`: مقداردهی مجدد داده‌های آزمایشی
